## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors bundled together with a universal loader called xcutorsLoader, designed for Windows desktop users who want a single hub to manage multiple executors.

### Is XCutors free to use?

Yes, XCutors is completely free. All included executors and the universal loader are distributed at no cost through this repository.

### What operating systems are supported?

XCutors currently supports Windows 10 and Windows 11 (64-bit). macOS and Linux are not supported at this time.

### What is xcutorsLoader and why should I use it?

xcutorsLoader is a universal loader that acts as a central hub for all included executors. Instead of downloading and managing each executor separately, you can launch, configure, and switch between them from one unified interface.

### How do I update the executors or the loader?

xcutorsLoader includes a built-in auto-update system. When a new version of any executor or the loader itself is available, you will be prompted to update automatically on launch.

### Can I add my own custom Lua scripts?

Absolutely. You can import custom scripts through the built-in script manager, use the integrated editor to write new ones, or drag and drop .lua files directly into the script library.

### My anticomponent flags XCutors as suspicious. Is it safe?

Script executors are commonly flagged by anticomponent software because they interact with external processes. XCutors is open-source and transparent — you can review the code yourself. Add an exception for the XCutors folder in your anticomponent settings if needed.

### Which Roblox versions are compatible?

XCutors and its included executors are maintained to support the latest stable version of the Roblox client. After a major Roblox update, allow some time for executor developers to release compatibility patches.

### Can I use multiple executors at the same time?

It is recommended to use only one executor at a time per Roblox instance to avoid conflicts. xcutorsLoader allows you to quickly switch between executors without restarting.

### Where can I find scripts to use with XCutors?

The loader includes a curated script library with popular community scripts. You can also find scripts on community forums, Discord servers, and script-sharing websites. Always review scripts before executing them.
